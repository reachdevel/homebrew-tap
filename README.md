# Homebrew tap for neotools

[neotools](https://github.com/reachdevel/neotools): modern, macOS-native replacements for the classic Unix commands that macOS has
outgrown (`du`, `df`, `top`, `find`, `lsof`, `ps`, `rm`, `tree` and more), written in Swift.

## Install

```sh
brew install reachdevel/tap/neotools
```

Or `brew tap reachdevel/tap` once, and then `brew install neotools`. The formula builds from source with the Command Line Tools 16 or newer, no Xcode needed (macOS 14
or newer) and takes a minute or two.

## Formulae

| formula | what it installs |
|---|---|
| `neotools` | `neodu`, `neodf`, `neotop`, `neofree`, `neotrash`, `neofind`, `neolsof`, `neotree`, `neops`, `neonet`, `neomedia`, `neodocs` and `neo-setup` |

Report problems with neotools itself in the [neotools issues](https://github.com/reachdevel/neotools/issues); problems with this
formula here.
