# Security policy

A vulnerability in neotools itself is reported as described in the
[neotools security policy](https://github.com/reachdevel/neotools/security/policy). For a problem in this tap (a formula that downloads
or runs something it should not), use **Security > Report a vulnerability** on this repository, or write to reachdevel@gmail.com.
Please do not open a public issue for a vulnerability.
